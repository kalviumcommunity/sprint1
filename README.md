# Telecom Network Outage Prioritization System

## Team Information
- Team: Team 05
- Campus: RVU
- Squad: 68
- Sprint: Semester 5 – Sprint 1

## Problem Statement
A telecom provider receives network outage alerts, customer complaint logs, and region-level usage metrics, but no monitoring workflow prioritizes which outages create the highest operational impact.

## Objective
Develop a system that prioritizes network outages based on their operational impact using outage alerts, customer complaints, and regional usage metrics.

## Proposed Solution
Build a dashboard that calculates an impact score for each outage and ranks incidents based on severity, affected users, complaint volume, and regional importance.

## Features
- Outage monitoring
- Priority ranking
- Impact score calculation
- Region-wise analytics
- Complaint analysis
- Dashboard

## Expected Outcome
- Faster response to critical outages
- Reduced downtime
